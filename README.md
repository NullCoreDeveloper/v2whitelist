# v2Whitelist

**v2Whitelist** — это глубоко модифицированный и минималистичный клиент на базе v2rayNG для Android. Главная цель проекта — обеспечить надежный обход ТСПУ (технических средств противодействия угрозам) и жестких блокировок провайдеров (Jamming), превратив сложный комбайн маршрутизации в безотказный "VPN в один клик".

## 🚀 Ключевые технологии и возможности

- **Абсолютный минимализм (One-Click VPN)**  
  Никаких сложных списков серверов, настроек маршрутизации и десятков непонятных переключателей на главном экране. Только одна большая кнопка «Старт» и лаконичный индикатор статуса (включая свежесть вашей подписки).
  
- **Достоверная проверка узлов (Real HTTP Profile Check)**  
  Вместо обычной проверки доступности TCP-порта (которая часто обманывается системами DPI), приложение "под капотом" параллельно поднимает тестовые V2Ray-ядра, пробрасывает через них **реальный HTTP-трафик** и измеряет фактическую задержку. Вы подключаетесь только к гарантированно рабочему узлу.

- **Анти-Глушилка (Survival Logic)**  
  Приложение умеет анализировать состояние сети. Если провайдер начинает жестко глушить зарубежный трафик (например, пингуется только Яндекс, а Google недоступен), срабатывает "протокол выживания": приложение мгновенно поднимает туннель через последний закэшированный сервер и незаметно **стягивает свежую подписку прямо через этот VPN-туннель**, восстанавливая доступ.

- **Подписки-"Матрёшки" и Автообновление**  
  Приложение использует динамическую ссылку-матрешку (`whitelist.txt`) для сокрытия реального URL подписки от блокировок. Специальный фоновый процесс (WorkManager) регулярно обновляет узлы, даже когда приложение закрыто. Главный экран автоматически подскажет актуальна ли подписка в данный момент.

- **Умная фильтрация локаций**  
  Возможность гибко настроить белый или черный список стран (по эмодзи-флагам), чтобы подключаться только к нужным регионам (система автоматически игнорирует ненадежные RU-хостинги).

- **Поддержка кастомных узлов и QR**  
  Несмотря на минимализм, оставлена полная свобода: вы можете сканировать QR-коды для добавления своих узлов или управлять сторонними подписками в расширенном меню.

## 🛠 Установка и обновления

Приложение имеет встроенную систему проверки обновлений (OTA). Все релизы собираются автоматически через **GitHub Actions** и выкладываются на вкладке [Releases](../../releases).
